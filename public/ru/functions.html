Функции: вычисление f(x)

Функция f(x) — это просто правило, превращающее число x в результат. Чтобы вычислить значение функции, подставьте данное число вместо x и посчитайте.

f(x) = 2x + 3

найти f(4) → подставляем 4 вместо x

f(4) = 2(4) + 3

f(4) = 8 + 3

f(4) = 11

Практика полностью работает в вашем браузере — без аккаунта и без хранения данных на сервере.
