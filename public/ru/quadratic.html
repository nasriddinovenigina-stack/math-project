Квадратные уравнения: решаем ax² + bx + c = 0

Решаем разложением на множители

Вопрос

Высота мяча описывается формулой, которая равна нулю ровно в два момента времени — когда его подбросили и когда он приземлился. Если эти моменты — решения уравнения x² − 5x + 6 = 0, когда мяч покидает землю и когда приземляется?

Идея

У квадратного уравнения обычно два решения для x. Один из способов — найти два числа, которые перемножаются в c и складываются в b, а затем разбить уравнение на два простых.

Одной фразой: найдите два числа, которые перемножаются в c и складываются в b.

Смотрим решение

x² − 5x + 6 = 0

ищем два числа, которые дают 6 при умножении и −5 при сложении → −2 и −3

(x − 2)(x − 3) = 0

любой из множителей может быть равен 0

x − 2 = 0   или   x − 3 = 0

x = 2   или   x = 3

Осторожно

Частая ошибка — найти два числа, которые правильно перемножаются, но забыть проверить сумму: 1 и 6 дают 6 при умножении, но в сумме 7, а не −5. Должны совпадать оба условия.

Почему это важно

Квадратные уравнения появляются везде, где что-то ускоряется или замедляется — брошенные мячи, торможение машины, кривые прибыли в бизнесе.

Формула корней квадратного уравнения

Вопрос

Движение другого мяча описывается уравнением 2x² − 7x + 3 = 0, но на этот раз не видно очевидной пары чисел для разложения на множители. Есть ли формула, которая работает всегда, при любых числах?

Идея

Формула корней решает ЛЮБОЕ уравнение вида ax² + bx + c = 0, даже когда разложить на множители сложно: x = (−b ± √(b² − 4ac)) ÷ (2a).

Одной фразой: подставьте a, b, c в x = (−b ± √(b² − 4ac)) ÷ (2a).

Смотрим решение

2x² − 7x + 3 = 0 → a = 2, b = −7, c = 3

сначала найдём дискриминант → b² − 4ac

(−7)² − 4(2)(3) = 49 − 24 = 25

√25 = 5

x = (7 ± 5) ÷ (2 × 2)

x = 3   или   x = 0,5

Осторожно

Частая ошибка — забыть про ± и посчитать только один ответ, или перепутать знак b: раз b = −7, то −b становится +7, а не −7. Выпишите отдельно a, b и c, прежде чем подставлять их в формулу.

Почему это важно

Формула корней работает всегда, даже когда разложение на множители не получается — это надёжный способ решить любое квадратное уравнение.

Введите оба решения через запятую, например 2, 3 или 3, 0.5 (порядок не важен; дроби вроде 1/2 тоже подходят). Для дробной части используйте точку «.», а не запятую.
