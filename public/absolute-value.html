What Absolute Value Means

The Question

The temperature is 7 degrees below freezing (−7°). How far is that from 0 degrees, regardless of direction?

The Idea

Absolute value means "distance from 0" — so it's always positive (or zero), no matter the sign of the number inside.

In one line: absolute value is just the distance from zero — always positive.

Watch It Solved

|−7| = ?

distance from 0 to −7 is 7

|−7| = 7

Watch Out

A common mistake is leaving the answer negative — writing |−7| = −7. The bars mean "distance," and distance is never negative.

Why It Matters

Absolute value shows up whenever direction doesn't matter, only size — how far off a target, how much error, how far below zero.

Solving Absolute Value Equations

The Question

You're standing at position 3 on a number line. You want to know every point that's exactly 5 steps away from you — in either direction. Where are they?

The Idea

An equation like |x − k| = n means "x is exactly n away from k." Since distance works both ways, there are usually two solutions: k + n and k − n.

In one line: drop the bars into two equations, one with +n and one with −n.

Watch It Solved

|x − 3| = 5

x − 3 = 5   or   x − 3 = −5

x = 3 + 5   or   x = 3 − 5

x = 8   or   x = −2

Watch Out

A common mistake is only solving x − 3 = 5 and stopping, missing the second solution entirely. Absolute value equations almost always have two answers — don't forget the negative case.

Why It Matters

This shows up whenever you need a range around a target — an acceptable margin of error, a tolerance in manufacturing, a temperature range.

For "distance from 0" problems, enter a single number. For "solve for x" problems, enter both solutions separated by a comma, e.g. 8, -2 (either order is fine).
