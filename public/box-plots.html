Box Plots & Interquartile Range

The Question

A sorted data set of 7 test scores is: 58, 63, 70, 75, 80, 88, 95. What is the interquartile range (IQR)?

The Idea

A box plot summarizes data using five numbers: the minimum, the first quartile (Q1, the median of the lower half), the median, the third quartile (Q3, the median of the upper half), and the maximum. The interquartile range (IQR = Q3 − Q1) measures how spread out the middle 50% of the data is.

In one line: split the data into halves around the median, find the median of each half (Q1 and Q3), then subtract.

Watch It Solved

data: 58, 63, 70, 75, 80, 88, 95

median = 75, lower half = 58, 63, 70; upper half = 80, 88, 95

Q1 = 63, Q3 = 88

IQR = 88 − 63 = 25

Watch Out

A common mistake is including the overall median in both halves when finding Q1 and Q3 — for an odd-sized data set, leave the middle value out of both halves before finding their medians.

Why It Matters

IQR is a more reliable "typical spread" than the full range because it ignores extreme outliers — it's what statisticians and box plots use to describe how consistent a data set really is.
