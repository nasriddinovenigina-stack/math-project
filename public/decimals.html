🔟Decimal Operations

Adding & Subtracting Decimals

The Question

You run 2.5 km on Monday and 1.75 km on Tuesday. How far did you run in total?

The Idea

To add or subtract decimals, line up the decimal points so the place values match, then add or subtract like normal, keeping the decimal point in the same place.

In one line: line up the decimal points, then add or subtract as usual.

Watch It Solved

2.50

+ 1.75

line up the decimal points, then add each column like whole numbers

= 4.25 km

Watch Out

A common mistake is not lining up the decimal points before adding — for example, adding 2.5 and 1.75 as if they were 25 and 175. Always line up the decimal point first so each digit matches its correct place value (ones, tenths, hundredths).

Why It Matters

Decimals are everywhere — money, measurements, sports times — anywhere you need more precision than whole numbers.

Multiplying & Dividing Decimals

The Question

A T-shirt costs 12.5 so'm. How much do 3 T-shirts cost? And if 3 friends split a 37.5 so'm bill evenly, how much does each pay?

The Idea

To multiply decimals, multiply the numbers as if there were no decimal point at all, then place the point so the answer has the same total number of decimal digits as the numbers you multiplied. To divide, just divide as usual, keeping the decimal point in the same column.

In one line: multiply or divide like whole numbers, then fix the decimal point afterward.

Watch It Solved

12.5 × 3

multiply as whole numbers: 125 × 3 = 375

12.5 has 1 decimal digit, so the answer needs 1 decimal digit too

12.5 × 3 = 37.5

37.5 ÷ 3

divide as usual, keeping the decimal point in the same place

37.5 ÷ 3 = 12.5

Watch Out

A common mistake when multiplying decimals is putting the decimal point in the wrong place. Always count the total decimal digits in the numbers you're multiplying, and put that many digits after the point in the answer.

Why It Matters

Multiplying and dividing decimals is how you calculate totals and splits for prices, measurements, and rates that aren't whole numbers.
