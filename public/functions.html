Functions: Evaluating f(x) & Finding f(x) from Two Points

Evaluating a Function

A taxi charges a 3,000 so'm base fee plus 2,000 so'm per kilometer. If f(x) = 2x + 3 gives the fare (in thousands) for x kilometers, what's the fare for a 4 km ride?

A function f(x) is just a rule for turning an input x into an output. To evaluate it, put the given number everywhere you see x, then work it out.

In one line: swap x for the given number, then simplify.

f(x) = 2x + 3

find f(4) → put 4 in place of x

f(4) = 2(4) + 3

f(4) = 8 + 3

f(4) = 11

A common mistake is only replacing x in one spot when it appears more than once, or adding before multiplying. Replace every x first, then follow the order of operations.

Functions describe how one thing depends on another — like how a taxi fare depends on distance, or how your pay depends on hours worked.

Finding a Function from Two Points

That same taxi company won't tell you the formula this time. You just know a 1 km ride costs 5,000 so'm and a 4 km ride costs 11,000 so'm. Can you figure out the fare formula yourself?

Given two points (x₁, y₁) and (x₂, y₂) on a line, you can rebuild the whole function f(x) = ax + b. First find the slope a (how fast y changes), then use one point to find b (the starting value).

In one line: find the slope between the points, then plug one point back in to find b.

Points: (1, 5) and (4, 11)

find the slope (a) first → a = (11 − 5) ÷ (4 − 1)

a = 6 ÷ 3

a = 2

use one point to find b → 5 = 2(1) + b

5 = 2 + b

b = 3, so f(x) = 2x + 3

A common mistake is finding a and stopping there. a only tells you the rate of change — without b, you don't know the starting fare (the value at x = 0). Always plug a point back in to solve for b.

This is exactly how pricing plans and taxi fares get built from real data — a company measures two data points and works backward to the formula.
